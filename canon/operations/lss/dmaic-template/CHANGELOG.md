# CHANGELOG — dmaic-template

## [1.0.0] — 2026-06-03

### Added
- Initial public release (Day-2 scaffold).
- Full D-M-A-I-C project template as markdown.
- SIPOC, VOC, charter, measurement plan, hypothesis test, control plan.
- Stdlib only; pure Python.

- No statistical engine (t-tests, ANOVA) — describe the test, don't run it.
- No visualization — pair with `pareto-script` for the M-phase analysis.
