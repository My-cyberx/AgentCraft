# CHANGELOG — flow-audit-deliverable

## [1.0.0] — 2026-06-03

### Added
- Initial public release (Day-1 scaffold per `agentcraft-strategy-brief.md` §12).
- 8-stage workflow: intake → BMC → PESTEL/5-Forces → gap → roadmap → vendors → package → delivery.
- 7-document deliverable in dated `~/clients/<slug>-<date>/` folder.
- Airtable CRM integration, Resend email delivery, Gemini cover image.
- Cost estimate: ~$0.54 per audit (vs $3K-$7.5K billed to client).

### Known limitations
- Single org per run; multi-org rollups are a future flow.
- Dashboard is interactive HTML only — no PDF print stylesheet.
- Mock intake data when sources are sparse; flagged in deliverables.
